Agents pay per call. Nobody learns who paid.

HTTP 402 settled in shielded Zcash: spendguard checks each payment, the merchant verifies with a viewing key alone.

Quickstart Try the live 402

Three steps. No account, no card.

  1. Ask

    The API answers 402 with a Zcash option in the standard x402 body.

  2. Pay

    spendguard checks the cap and host, then the agent pays shielded.

  3. Retry

    The facilitator finds the memo with its viewing key; the API answers 200.
