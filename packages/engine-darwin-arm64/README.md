# kage-x402-engine-darwin-arm64

Prebuilt Kage engine (Rust, from [zec-shielded-x402](https://github.com/nickthelegend/zec-shielded-x402) `crates/`) for macOS arm64: `x402z-mcp`, `x402z-agent`, `x402z-facilitator`. You don't install this directly; `kage-x402` picks it up. Build from source with `cargo build --release -p x402z-mcp -p x402z-agent -p x402z-facilitator`.
