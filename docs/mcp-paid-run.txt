================ Prompt (verbatim) ================
You are an AI agent that pays for HTTP APIs with the `kage` MCP tools (shielded Zcash testnet payments, checked by spendguard). Do these steps in order and do not skip any:
1. Call the kage spend_status tool.
2. Call the kage paid_fetch tool with url http://127.0.0.1:4220/api/quote.
3. If paid_fetch returned status "settlement_pending", the payment is broadcast and waits for a block (about 75 seconds). Run the shell command `sleep 90`, then call the kage redeem_payment tool with the same url and the txid and memoNonce that paid_fetch returned. Repeat sleep 90 + redeem_payment until it returns status 200 (at most 8 times). Never call paid_fetch again while that payment is pending.
4. Call the kage tab_fetch tool with url http://127.0.0.1:4220/api/quote and buy 3. If it returns status "tab_pending", run `sleep 90` and call tab_fetch again with the same url (no buy), until it returns status 200 (at most 8 times).
5. Call the kage tab_fetch tool twice more with the same url.
6. Call the kage ledger_tail tool with n 10.
Then summarize: each txid that was paid, whether X-PAYMENT-RESPONSE said success, and how many tab tokens are left.
